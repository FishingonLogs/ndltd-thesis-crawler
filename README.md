# NDLTD 博碩士論文爬蟲工具

對「臺灣博碩士論文知識加值系統」(https://ndltd.ncl.edu.tw) 進行查詢並批次擷取論文 metadata 的桌面工具。
支援進階查詢、爬取完成自動匯出 CSV、斷點續爬，並在遇到圖形驗證碼時由你手動完成驗證。

> 僅擷取書目 metadata（題名、作者、摘要、參考文獻等），不下載論文全文 PDF。

---

## 一、系統需求

- **Windows 10／11**
- **Python 3.11 以上**（請至 https://www.python.org/downloads/ 安裝；安裝時勾選「Add Python to PATH」）
- 可連網（會下載一次瀏覽器核心 Chromium，約 150MB）

## 二、安裝（只需做一次）

1. 把整個資料夾解壓縮到任意位置（路徑建議不要有特殊符號）。
2. 連點兩下執行 **`安裝.bat`**。它會自動：
   - 建立獨立的 Python 環境（`.venv`）
   - 安裝所需套件
   - 下載瀏覽器核心（Chromium）
3. 看到「安裝完成！」即可。

> 若 `安裝.bat` 失敗，多半是沒安裝 Python 或沒加入 PATH。請重裝 Python 並勾選「Add Python to PATH」。

## 三、啟動程式

連點兩下 **`啟動.bat`**，會開啟「NDLTD 博碩士論文爬蟲工具」視窗。

---

## 四、使用說明

視窗左邊是查詢設定、右邊是進度與即時日誌，下方有「停止」「匯出 CSV」。

### 模式一：搜尋模式（依條件查詢）

1. 左上選「**搜尋模式**」。
2. 在「**進階查詢條件**」設定查詢列，每列＝「**欄位 + 關鍵字**」：
   - 欄位可選：不限欄位／論文名稱／研究生／指導教授／校院名稱／系所／關鍵詞／摘要…
   - 按「**＋ 新增查詢列**」可加更多列；第 2 列起前面可選 **and／or／not** 組合（最多 10 列）。
   - 例：第 1 列「研究生＝王小明」、第 2 列「and 校院名稱＝臺灣大學」。
3. 「**限縮條件**」可勾選學位（碩士／博士）、設定畢業學年度範圍（民國學年度，0＝不限）。
4. 按「**開始爬取**」。

### 模式二：ID 清單模式（已知論文編號）

1. 左上選「**ID 清單模式**」。
2. 按「**匯入 ID 清單**」選一個 CSV 檔。CSV 需有一欄標題為 `thesis_id`，每列一個論文編號（見隨附的 `thesis_ids_範例.csv`）。
3. 按「**開始爬取**」。

### 關於圖形驗證碼（重要）

網站在使用量大時會跳出「驗證碼檢查機制」。本工具偵測到時會：
1. 自動把瀏覽器視窗顯示出來；
2. **請你在那個瀏覽器視窗輸入圖中的字元**；
3. 完成後**回到本工具，按對話框的「確定」**，即會繼續。

### 速率控制

每筆之間會等待數秒（預設 2～5 秒）以降低網站負擔、減少觸發驗證碼。屬正常現象，請耐心等候。

### 停止與續爬

- 按「**停止**」會在完成當前一筆後停止（停止時**不會**自動匯出）。
- 已成功擷取的論文會記在資料庫，**下次再跑相同論文會自動跳過**（不重複擷取），失敗的則會重試。

## 五、結果在哪裡？

爬取「正常完成」後會自動匯出到 **`output\`** 資料夾：

- `thesis_<日期時間>.csv` — 論文 metadata（**目前資料庫中所有已完成的紀錄**）
- `run_<日期時間>.log` — 本次執行紀錄（成功／跳過／失敗逐筆）

也可隨時按「**匯出 CSV**」手動匯出。

### CSV 欄位

論文永久網址、研究生（中／外）、論文名稱（中／外）、指導教授、口試委員、口試日期、學位類別、校院名稱、系所、學門、學類、論文種類、出版年、畢業學年度、語文別、頁數、中文／外文關鍵詞、相關次數(citation_stats)、**中文摘要、外文摘要、參考文獻**等。

> **注意：用 Excel 開啟的提醒**
> 參考文獻欄可能很長，超過 Excel 單一儲存格上限（32,767 字）時，Excel 會把它顯示成多行/錯亂。**CSV 檔本身是正確的**，建議改用 **LibreOffice Calc**、或用程式（pandas）讀取；若只看書目以外的欄位，用 Excel 無妨。
> 另：少數罕用字（如某些人名）站方使用造字區字元，可能顯示成方框，這是網站原始資料如此。

## 六、進階設定（選用）

在程式資料夾放一個 `config.json` 可調整行為（可參考隨附的 `config.example.json`）：

| 設定 | 說明 | 預設 |
|------|------|------|
| `delay_min` / `delay_max` | 每筆間隔秒數範圍 | 2.0 / 5.0 |
| `headless` | `true`＝平常隱藏瀏覽器（驗證碼時才顯示）；`false`＝全程顯示 | true |
| `output_dir` | 匯出資料夾 | "output" |
| `auto_export` | 完成後是否自動匯出 | true |
| `db_path` | 資料庫檔名 | "ndltd.db" |

## 七、常見問題

- **搜尋一直跳驗證碼？** 使用量大時較頻繁，依提示手動解即可；放慢速率（調大 delay）可減少。
- **想重新從零開始？** 關閉程式後刪除 `ndltd.db`（會清空已擷取紀錄）。
- **筆數比預期少？** 多條件（and）會縮小範圍；確認條件是否過嚴。
- **請尊重網站**：本工具僅供學術／個人研究使用，請勿高頻大量爬取。
